# Learning route

The [30-milestone map](MILESTONES.md) traces the qubit memory problem from a single noisy slot to a finite tester guarantee and a matching order of seed cost. Start with the [Watrous bridge](WATROUS_BRIDGE.md) for the relevant textbook sections and the conventions used here.

The [scientific model](../science/model.md) specifies the experiment. The [seed construction](../science/seed.md), [process bound](../science/process-bound.md), and [entropy converse](../science/converse.md) give the independent parts of the main result. The [independent-process comparison](../science/independent-process.md) and [control robustness](../science/control-robustness.md) address extensions of that model.
